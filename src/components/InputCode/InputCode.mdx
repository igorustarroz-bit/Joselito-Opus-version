# Input-Code

## Introducción

Código de verificación por casillas (SMS / correo): de 3 a 6 casillas de 40 px con avance automático y pegado del código completo.


Figma: `Input-Code` (`63264:50565`)

## Subtemas

Subtemas soportados: `light-white`, `light-grey`, `dark-red-primary`, `dark-black-neutral`

## Comportamiento

- Escribir avanza a la siguiente casilla; Borrar vuelve a la anterior; ← → navegan.
- Pegar un código lo reparte entre las casillas.
- Completo → estado Filled y onComplete.
