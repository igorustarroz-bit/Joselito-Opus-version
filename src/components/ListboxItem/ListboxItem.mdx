# listbox_Item_Dropdown

## Introducción

Opción de una lista desplegable o de filtros: texto con descripción e imagen opcionales y, a la derecha, un radio (selección única), una casilla (múltiple) o una X para eliminar. Con radio o casilla toda la fila es clicable.


Figma: `listbox_Item_Dropdown` (`49650:11827`)

## Anatomía

- Imagen 1:1 de 48 px (opcional)
- Texto y descripción (opcional)
- Control: Checkboxes-Radios o X de 20 px

Subtemas soportados: `light-white`, `light-grey`, `dark-red-primary`, `dark-black-neutral`

## Comportamiento

- Hover sobre la fila: el control pasa a su estado Hover.
- Clic en la fila marca el radio o alterna la casilla (label nativo).
- Delete: la X ejecuta onDelete.
