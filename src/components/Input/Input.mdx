# Input

## Introducción

Campo de formulario con etiqueta flotante: vacío muestra la etiqueta dentro; al enfocar o escribir sube y aparece el valor. Mensaje inferior de ayuda, error o validación. Versión `Dropdown` que abre un Listbox de opciones. Dos tamaños (Big 72 px, Small 56 px). Ocupa el ancho de su contenedor.


Figma: `Input` (`49118:2300`)

## Anatomía

- Campo con borde de 1 px (alto por token)

## Comportamiento

- Vacío: la etiqueta ocupa el sitio del valor; al enfocar o con valor, flota arriba (estilo Label-In).
- Hover: colores Forms/Hover (solo en estado por defecto).
- Focused: colores Forms/Focused (también con el desplegable abierto).
- Error / Validated por prop; Disabled nativo.
- Dropdown: clic abre el Listbox debajo (a 8 px); se cierra al elegir, con Esc o clic fuera.

## Accesibilidad

- Input nativo asociado a su etiqueta (label for).
- El mensaje se enlaza con aria-describedby; error con aria-invalid.
- Dropdown: botón con aria-haspopup/aria-expanded; opciones como radios dentro del Listbox.
