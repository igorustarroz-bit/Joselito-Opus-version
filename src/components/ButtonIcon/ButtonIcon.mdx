# Button-Icon

## Introducción

Botón cuadrado que solo muestra un icono (por defecto una flecha). Se usa para acciones compactas: avanzar/retroceder en carruseles, cerrar, volver, enviar un campo… Tres tipos (Primary relleno, Secondary relleno con borde, Terciary solo borde) y cinco tamaños (XL solo en Primary). Es `<a>` con `href` y `<button>` sin él.


Figma: `Button-Icon` (`49038:9364`)

## Anatomía

- Contenedor cuadrado (tamaño por token responsive, sin radio)
- Borde interior de 1 px según tipo y estado
- Icono centrado (32/24/24/20/16 px según tamaño)

## Subtemas

Subtema por defecto: `light-white`

Subtemas soportados: `light-white`, `light-grey`, `dark-red-primary`, `dark-black-neutral`

No fija subtema: los tokens Button/* se adaptan al subtema del contenedor.

## Comportamiento

- Hover: tokens Button/TIPO/Hover (Primary gana un borde de 1 px).
- Focus (teclado): tokens Button/TIPO/Focused + contorno de 1 px separado 4 px (:focus-visible).
- Selected: estado de toggle por prop (`selected` → aria-pressed).
- Disabled: tokens Button/TIPO/Disabled; sin borde; no recibe foco ni hover.
- Tamaño fijo cuadrado; el icono no cambia de tamaño entre estados.

| --- | --- | --- |
| color | `--button-TIPO-ESTADO-fill` | fondo (Primary y Secondary siempre; Terciary solo Selected y Disabled) |

| radius | `--layout-corners-none` |  |

## Propiedades

| Nombre | Descripción | Por defecto | Control |
| --- | --- | --- | --- |
| type | `Primary` (relleno), `Secondary` (relleno + borde) o `Terciary` (solo borde). | Primary | inline-radio |
| size | Lado del cuadrado: XL 104 · L 64 · M 56 · S 48 · XS 40 px (tokens Layout/Button/TAMAÑO/Size, responsive). XL solo existe para Primary en Figma. | L | inline-radio |
| icon | Icono del set (Instance swap en Figma). En el máster: ArrowRight. | arrow-right | select |
| label | Nombre accesible (`aria-label`). Obligatorio: el botón no tiene texto visible. | "Botón" | text |
| href | Si se pasa, se renderiza `<a>`; si no, `<button>`. | — | text |
| selected | Estado seleccionado (toggle); se expone como `aria-pressed`. | false | boolean |
| disabled | Desactiva el botón. | false | boolean |
| state | Solo documentación: fuerza Hover o Focussed. En producción son estados nativos. | — | select |
| theme | Fija un subtema (`data-theme`). Por defecto hereda el del contenedor. | — | text |

## Guía de contenido

| Campo | Límite | Notas |
| --- | --- | --- |
| Icono |  | Un icono del set que exprese la acción (flecha, cerrar, etc.). |
| Label |  | Texto para lectores de pantalla: verbo de la acción ("Siguiente", "Cerrar"). |

## Accesibilidad

- Siempre con `label` (aria-label): no hay texto visible.
- Foco visible con teclado (:focus-visible).
- `selected` se anuncia como botón pulsado (aria-pressed).
- El icono es decorativo (aria-hidden).
