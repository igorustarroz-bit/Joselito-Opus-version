# Icon

## Introducción

Iconos del sistema (136, página Brand Assets › Icons de Figma) como componentes SVG optimizados. Heredan el color del texto (`currentColor`), así que se colorean con el token de texto o de icono del contenedor. El tamaño sigue el máster **Icon Sizer** (L 32 · M 24 · S 20 · XS 16 · XXS 12 px). Ficheros en `src/assets/icons/<nombre>.svg`; el mapa nombre ↔ nodo de Figma está en `maps/icons.json`.


Figma: `Icon Sizer` (`49026:6521`)

## Anatomía

- SVG 32×32 (viewBox) escalado al tamaño del Icon Sizer
- Trazo de 1,5 px (escala con el icono)

## Subtemas

Subtema por defecto: `light-white`

Subtemas soportados: `light-white`, `light-grey`, `dark-red-primary`, `dark-black-neutral`

Hereda el color del texto del subtema.

## Comportamiento

- Sin interacción propia: lo usan Button, Button-Icon, NavButton, Tabs, Input…
- El color se controla con `color` en el contenedor (tokens Texts/* o Strokes-Icons/*).
