# Modal_Lightbox

## Introducción

Ventana emergente para avisos, selección de formato y vídeos: Basic (texto), Ticket (texto + botones), List (opciones + botones), Video (16:9 con cerrar) y Collapsed (barra de producto con "elige"). Puede usarse como modal real sobre Overlay.


Figma: `Modal_Lightbox` (`60581:102087`)

## Anatomía

- Cabecera: título + Button-Icon Terciary XS (X)
- Cuerpo (slot): texto u opciones
- Pie: RowButtons (Ticket, List)
- Video: Aspect Ratio 16:9 + cerrar
- Collapsed: foto 48 + nombre/precio + Button Primary S

## Subtemas

Subtema por defecto: `light-white`

Subtemas soportados: `light-white`, `light-grey`, `dark-red-primary`, `dark-black-neutral`

Hereda el subtema.

## Comportamiento

- Modal: Esc, clic en el Overlay o X cierran; el foco queda dentro y vuelve al elemento anterior al cerrar.
- List: selección única (radios).
- Collapsed: en móvil (por debajo de 768 px) se oculta la foto.
