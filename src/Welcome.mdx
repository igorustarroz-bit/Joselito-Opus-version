# Joselito

Design system en código generado desde Figma con el proceso **design-to-code de Hanzo**.

- **Tokens**: generados desde las variables de Figma (`npm run tokens`). No se editan a mano.
- **Orden**: Tokens → Componentes → Módulos → Page templates.
- **Subtemas**: usa el selector "Subtema" de la barra superior; "Auto" muestra el default de cada elemento.
- **Breakpoints**: usa el selector de viewport (mismos breakpoints que Figma).

Estado del trabajo: `PLAN.md` en el repositorio.
