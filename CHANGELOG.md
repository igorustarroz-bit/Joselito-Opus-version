# CHANGELOG

Cambios entre Figma y código. Formato: `fecha · elemento · tipo (✅ añadido / 🎾 cambiado / 🔨 arreglado / 🗑️ borrado / 📦 obsoleto) · origen (Figma | código) · descripción`.
Si el código diverge de Figma a propósito, se anota aquí con el motivo (y en la página ⚙️ Changelog del Figma si existe).
